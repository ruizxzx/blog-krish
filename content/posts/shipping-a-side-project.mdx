I've started this particular project four times over two years. Each time, it died somewhere around week three. Here's what was different this round.

## Smaller scope, on purpose

Version one tried to do everything at launch. Version five does one thing and does it in an afternoon's worth of code.

```ts
function shipSomethingSmall() {
  return "today, not eventually";
}
```

## A public deadline

Telling exactly one other person a real date turned out to matter more than any productivity system. Accountability to a system is easy to negotiate with. Accountability to a person is not.

## What I'd tell past me

Cut the feature list in half, then in half again. The version that actually ships is never the version you originally imagined — and that's fine.
