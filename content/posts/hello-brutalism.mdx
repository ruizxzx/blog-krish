Most personal sites look the same: a soft sans-serif, a rounded card, a pastel gradient nobody asked for. This one doesn't. Here's why.

## The case for rough edges

Neo-brutalism on the web borrows from the architectural movement's honesty about materials — concrete looks like concrete, seams show, structure isn't hidden behind decoration. Applied to a UI, that means:

- Borders that are actually borders (3–4px, solid black)
- Shadows that are hard-edged, not blurred into a soft glow
- Buttons that visibly move when you press them

None of it is subtle. That's the point.

## Built on markdown, not a database

Every post here — including this one — is a single `.mdx` file with some frontmatter on top. No admin panel, no database migrations, no CMS login screen. If I want to publish, I open my editor, write, and push.

```bash
touch content/posts/my-new-idea.mdx
```

That's the whole publishing workflow.

### Why that matters

A blog should be as low-friction to write for as a text file, because that's exactly what it is under the hood. The moment publishing requires opening a dashboard, some posts just... don't get written.
